Turn on a real collector (optional, free)

The site ships with no third-party analytics. Two supported paths:

  1. GoatCounter (free for non-commercial, privacy-first, has a dashboard + API): create a code at goatcounter.com, then set data-goatcounter="yourcode" on the analytics script tag. Every pageview and the lead conversion are then counted server-side.
  2. Your own endpoint: point data-endpoint at any URL that accepts a JSON POST ({site, sent, records[]}) — a Cloudflare Worker, Vercel function, or Formspree-adjacent webhook. Records are sent with sendBeacon and survive navigation.

Events are buffered locally first (aih:analytics:v1) and only sent when a collector is configured — Do Not Track and Global Privacy Control switch sending off entirely.
