10 agent tools that survive real use (the rest are hype)

We run autonomous agents daily. Most tooling looks great in a demo and falls over under load. These are the ones that held up.

The survivors

  1. Version control discipline (git + gh CLI). Scoped branches, cherry-picked commits, and honest CI state. The single highest-leverage "tool" in any agent pipeline.
  2. Static verification harnesses. Explicit, versioned test lists that must pass before a merge — not auto-discovered, not skippable.
  3. Circuit-breaker / verification gates. Orchestrator-level blocks that stop a false-completing agent from shipping broken work.
  4. Provenance-bound memory. Every action logged with a source run ID, evidence label, and receipt — so "done" is auditable, not asserted.
  5. Append-only ledgers. History that can't be rewritten to look cleaner. Trust requires it.
  6. Sandboxed evaluation. Untrusted generated code runs isolated before it touches anything real.
  7. Cost-aware model routing. Switching to free/cheap models when the task doesn't need a frontier model — real money saved.
  8. Health-checked servers. Readiness verified with an actual endpoint probe, not a blind sleep loop.
  9. Subagent fan-out. Parallel isolated contexts for reasoning-heavy work that would flood one context window.
  10. Honest failure reporting. The tool that says "I couldn't do it" instead of fabricating a result. Rarer and more valuable than any feature.

What fell over

Anything that auto-commits the whole working tree, anything that reports success without a read-back check, and any "autonomous money bot" — platforms deny unattended accounts, and the economics don't survive contact with reality.
