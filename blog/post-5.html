Cost-aware model routing: pay for frontier only when it matters

Most of your agent's work doesn't need a frontier model. Routing it to a cheap or free one is the single easiest way to cut an AI bill — without losing quality where it counts.

The mistake: one model for everything

Point every task at the biggest model and you pay frontier prices for trivial work — summarizing a log, extracting a field, drafting a routine email. The bill balloons and the quality gain is invisible, because the task never needed the frontier model in the first place.

What we do instead

  • Default to cheap/free. Routine, well-scoped tasks run on a budget model by default.
  • Escalate only on signal. A task that fails, needs deep reasoning, or produces a deliverable worth real money gets routed to a frontier model.
  • Pin the model per job. Cron jobs and recurring agents are pinned to a specific model so they don't silently drift onto an expensive one when the global default changes.

The result

We run a fleet of agents and cron jobs continuously, and the cost stays flat — because the expensive model is the exception, not the default. The discipline is the same as any budget: spend where it returns, save where it doesn't.
